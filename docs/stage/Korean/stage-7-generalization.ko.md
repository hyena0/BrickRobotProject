# 7단계: 일반화

**Latest:** Day 8 · **목표:** 처음 보는 로봇에서도 코드 수정 없이 같은 파이프라인이 동작함을 보여줍니다.

## 시험 세트

| 출처 | 이유 | 정답 |
|---|---|---|
| **절차적 생성 팔** (`src/gen/procedural.py`) | 직접 만든 LDraw 생성기: 회전 관절 2~4개, 무작위 링크 길이, 무작위 기어 트레인(1~3단, 아이들러), 선택적으로 중공 관절을 지나는 축 | 생성 방식으로 정확히 알 수 있음. 전부 공개 가능 |
| 라이선스가 명확한 공개 모델 (예: 공식 세트 모델이나 교육용 모델) | 다른 사람이 만든 실제 설계 | 설명서나 공식 프로그램 |

주 시험 세트는 절차적 생성 팔입니다. 라이선스 문제가 없고, 개수 제한이 없으며, 정확한 정답이 따라옵니다.

## 작업

1. **절차적 생성기** (약 3시간): LDraw 파일과 정답 기구학을 함께 출력. 평면 2~3관절 팔부터 시작하고, 이어서 연동 관절 하나를 추가.
2. **일괄 실행** (`src/eval/batch.py`): 생성된 로봇 10~20개에 에이전트 실행. 분당 150회 제한을 지키거나, Baseten 크레딧을 받았다면 일부를 Muse Spark Open으로 실행.
3. **공개 모델 하나:** 한 번 실행하고 결과 보고.
4. **보고:** README와 영상용 표 하나 (로봇, 자유도, 링크 분할 정확도, 기어비 오차, IK 성공률).

## 선택: 모델 비교

같은 일괄 실행을 `muse-spark-1.3-contributor`와 Muse Spark Open으로 각각 돌려, 정확도와 비용을 나란히 보고합니다.
