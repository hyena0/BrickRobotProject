# 계획 추가안: 생성 로봇, 데모 전략, VLA (초안)

**날짜:** 2026년 10월 29일 (Day 3) · **상태: 초안, 아직 병합하지 않음.** `PLAN.md`(v1), `PLAN.v2.md`, 기존 단계 문서는 모두 그대로 둡니다. 이 추가안은 일정에서 각 부분이 확정될 때 단계적으로 병합합니다 (8절).

## 1. 결정 사항

1. **첫 실물 데모:** MR JOS 기반 로봇.
2. **영상:** MR JOS 기반 로봇은 모든 장면에서 **블러 처리**하고, 추론 결과는 추상적인 형태로만 보여줌.
3. **대표 로봇:** 직접 만든 모듈로 **생성기가 설계한 로봇** (5D단계).
4. **가상 검증 후 실물로:** 생성 로봇을 가상으로 검증(왕복 검증)한 뒤 **실물로 다시 조립**.
5. **생성 로봇의 제어 로직:** 같은 범용 파이프라인(로봇 패키지 → 컨트롤러 패키지, 5A~5C단계)으로 만들고, 이어서 **VLA로 확장** (6B v2: 시뮬레이션 먼저, 다음에 시뮬레이션 → 실물).
6. **선택 목표:** 6A(MR JOS로 가리키기)는 제외. 가리키기 작업은 생성 로봇의 VLA가 수행.
7. **GUI:** 5C 화면은 검증에 필요한 만큼으로 축소, CLI 마법사 우선.

## 2. 이유

- MR JOS 설계는 공개할 수 없고, 디자이너의 회신도 없음.
- 직접 만든 모듈로 생성한 로봇은 모듈, LDraw, 메시, 렌더, 실물 영상, VLA 데이터까지 모두 공개 가능.
- 이야기 흐름: 기존 로봇을 읽고(추론) → 움직이고(실물, 블러) → 새 로봇을 설계하고(생성) → 다시 읽어 확인하고(왕복 검증) → 조립하고 → 생성된 로직으로 제어하고 → VLA로 움직임.

## 4. 생성 로봇의 핵심 제약

| 제약 | 이유 |
|---|---|
| **가지고 있는 부품만으로 구성** (`config/inventory.local.yaml`) | 실물로 다시 조립해야 하므로, 생성기가 부품 목록을 보유 부품과 대조 |
| **가능하면 EV3 브릭 1개** (모터 4개, 센서 4개 이하. 예: 관절 3~4개) | 배선이 단순하고 블루투스 중계가 필요 없음. 5B 프로토콜은 그대로 적용 |
| **가능한 관절마다 원점 센서** (모듈 안에 터치 센서 장착부) | 새 로봇에서도 안전한 원점 복귀와 센서 기반 범위(5A/5C) 사용 |
| **분해 순서** | 부품을 MR JOS 기반 로봇에서 가져오므로(확정), **MR JOS 실물 작업(5C)을 모두 끝내고 촬영한 뒤에 분해** |
| **최적 부품 사용** | 부품 = MR JOS 로봇 부품 + 제한된 여분. 생성기가 이 범위 안에서 부품 수와 종류를 최소화 (4a절) |

### 4a. 보유 부품과 부품 최적화

- **보유 부품 출처:** 1단계에서 이미 파싱한 MR JOS 로봇의 부품 목록(정확한 개수) **+** 여분 부품을 직접 센 짧은 목록 → `config/inventory.local.yaml` (비공개, git 제외). 공개하는 것은 생성 로봇 자체의 부품 목록뿐.
- **귀한 부품은 절대 한도:** 모터(MR JOS 로봇 기준 라지 2개, 미디엄 4개), 터치 센서(4개), 컬러 센서(1개), EV3 브릭, 턴테이블, 큰 기어. 여분이 있으면 더함.
- 설계 에이전트와 생성기의 **최적화 우선순위**:
  1. 보유 부품 안에 들어갈 것 (필수 조건).
  2. 사양(도달 거리, 범위)을 허용 오차 안에서 만족.
  3. 부품 **종류** 최소화 (조립이 빠르고 실수가 줄어듦).
  4. 전체 부품 **개수** 최소화.
  5. 귀한 부품보다 수량이 많은 부품(빔, 핀, 축)을 우선 사용.
- **모터 배치 기준:** 하중을 받는 관절(어깨, 팔꿈치)에 라지 모터, 베이스 회전과 손목에 미디엄 모터.
- **되돌리기 어려움:** 분해는 쉽게 되돌릴 수 없음. 분해 전에 MR JOS 로봇의 영상 전체, 포트 배선, 측정값, 5C 보고서를 저장. `.io` 파일은 비공개로 보관해 나중에 다시 조립할 수 있게 함.

## 6. 영상과 블러 원칙

| 부분 | 로봇 | 보여주는 것 | 공개 수준 |
|---|---|---|---|
| 추론 | MR JOS 기반 (비공개) | 추상적인 결과만: 기본 도형, 관절축, 연동 설명, 지표 | 추상 |
| 실물 (첫 데모) | MR JOS 기반 | 원점 복귀, 목표 도달, 센서 정지 | **로봇 블러** (추적 마스크, 모든 프레임) |
| 생성 | 생성 로봇 | 사양 → 설계 에이전트 → 조립 → 왕복 검증 | 전부 공개 |
| 실물 조립 | 생성 로봇 | 렌더 옆에 놓은 조립된 실물 | 전부 공개 |
| 제어 + VLA | 생성 로봇 | 실제 메시를 쓴 콘솔, 생성된 제어 로직, 시뮬레이션 VLA 가리키기, 이어서 실물 | 전부 공개 |
| 로드맵 | – | 모바일 허브, 교육 키트, 모듈 종류 확대 | – |

- 공개 영상에서 MR JOS 로봇의 콘솔 화면은 기본 도형만 사용하고, 비공개 메시 모드는 보여주지 않음.
- 나중에 디자이너가 허락하면: 블러를 없애고 출처를 표기. 나머지는 그대로.
