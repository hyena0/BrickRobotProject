# 6단계 여유일 실물 계획 (stretch 문서 비교)

6단계 시뮬레이션(VLA 학습·평가)은 끝났다. 실물은 여유일에만 하며,
이 문서는 stretch 문서(`stage-6-stretch.ko.md`의 S.1~S.3, B2.1~B2.3)와
추가 문서 §7 + `physical_session.ko.md`의 두 방식을 비교한다.
구현은 포함하지 않는다.

## 방식 개요

| 구분 | 실물 카메라 (B2) | 디지털 트윈 |
|---|---|---|
| 입력 | 실물 사진 + 지시문 | 슬롯 색 입력 + 지시문 |
| 시각 | 휴대폰 고정 촬영 | 가상 이미지 렌더 |
| 추론 | Mac에서 ckpt 1회 | Mac/콘솔에서 ckpt 1회 |
| 실행 | 청크/AP 전체 10Hz | 유지 자세만 저속 1회 |

## 준비물

| 항목 | 실물 카메라 | 디지털 트윈 |
|---|---|---|
| 카메라 | 휴대폰+삼각대암 1대 | 불필요 |
| 보정 | ArUco 4개, 체커보드 | 매트 종이+자 |
| SW | S.3 호모그래피, SAM | 트윈 패널(완성) |
| 데이터 | 실물 사진 추가시 | 불필요 |

- 실물 카메라는 stretch S.1(50~60cm 고정), S.3(ArUco 호모그래피,
  오차 10mm 이하 확인)이 선행 조건이다.
- 트윈은 슬롯 종이(`slots_mat_a3.pdf`)와 콘솔만 있으면 된다.

## 절차

실물 카메라: 카메라 고정 → S.3 보정 → 실물 사진과 가상 이미지
나란히 비교 → B2.1(촬영→리사이즈→추론→안전점검→화면표시→Enter) →
B2.2 20회 시행(색마다 5회) → 성공률 나란히 보고.

디지털 트윈: 블록을 S1~S6에 배치 → 색 입력 → 저장 → 트윈 실행
(가상 이미지+정책 확인) → 유지 자세 저속 전송 → 휴식 자세.

실물 사진과 가상 이미지 비교에서 어긋나면(조명·색감·구도):
도메인 랜덤화(색조·밝기·책상색·조명·카메라 jitter) 후 재학습한다.
현재 학습 데이터의 랜덤화는 카메라 ±10mm가 전부다.

## 시간

| 구분 | 실물 카메라 | 디지털 트윈 |
|---|---|---|
| 준비 | 2~3시간 | 30분 이내 |
| 20회 시행 | 약 1시간 | 약 30분 |
| 재학습시 | +1시간 | +1시간 |

## 위험

| 구분 | 실물 카메라 | 디지털 트윈 |
|---|---|---|
| 카메라 이동 | 보정 무효, 재보정 | 해당 없음 |
| 조명·색감 | 오인식, 재학습 | 영향 없음 |
| 안전 | 청크 전체 실행 | 유지 1자세만 |
| 의미 | 실물 성능 측정 | 화면 내 성능만 |

## 권장 순서

트윈으로 먼저 20회를 돌려 청크 품질을 확인한다. 트윈 성공률이
낮으면 실물 카메라로 넘어가도 결과는 같으니, sens 판정과 재학습
여부가 먼저다. 실물 카메라는 트윈이 통과한 뒤 실물 성능을 증명할
때만 쓴다.
