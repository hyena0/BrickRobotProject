# 6단계 추가 문서: 시뮬레이션 VLA 우선 (현재 상황 반영)

**상태: 추가 문서.** `stage-6-stretch.ko.md`(기존 6단계)와 `stage-6b-vla-generated.ko.md`는 그대로 두고, 이 문서가 우선합니다. 6단계 세션은 이 문서부터 읽고, 나머지는 기존 6단계 문서의 **B(시뮬레이션 VLA)**를 따릅니다.

## 1. 범위 결정

| 항목 | 기존 | 현재 |
|---|---|---|
| A. 실물 가리키기 (Spark + SAM + 카메라) | 선택 목표 | **보류** (카메라 설치·캘리브레이션 시간 없음) |

## 2. 기존 6단계 B와 일치하는 부분 (그대로 따름)

- 로봇: `robot_inferred` 기본 도형 MJCF (메시 없음)
- 색깔 블록 3~4개, 80mm 이상 간격, 무작위 회전
- 영어 지시문 템플릿 (B.2), 에피소드 구성 5초·50스텝 (B.3)
- 정답 시연 = IK 기반 `point_at`, LeRobot 형식 400개 (B.4)
- 사전 점검 (B.5), Modal 학습 설정 (B.6), 평가 두 방식과 지표 (B.7)
- 데이터와 가중치에는 기본 도형만 포함

| 항목 | 기존 6단계 | 변경 | 이유 |

| 완료 판정 | 지표 보고 | **표 + 그림 증거**가 있어야 완료 | 5C 교훈 |

## 4. 진행 단계

| 단계 | 내용 | 위치 | 통과 기준 | 시간 제한 |
|---|---|---|---|---|
| **6.0 장면** | 받침대 평면, 블록, 가상 카메라, 범위 함수 공유 | 로컬 | 예시 렌더 9장(3×3), 블록 모두 보임, 팔은 화면 밖 | 1.5시간 |
| **6.1 정답 시연** | `point_at`(집게 끝, 경유점 120mm → 60mm → 유지 1초 → 휴식) | 로컬 | 성공률 95% 이상, 색 균형 23~27%, 범위 위반 0 | 1.5시간 |
| **6.2 시험 실행** | 시연 20개, 200스텝, 저가 GPU, 타임아웃 30분 | Modal | 학습 → 저장 → 불러오기 → 추론 1회 완료, 비용·시간 기록 | 1시간 |
| 6.3 본 학습 | 시연 400개 (360/40), 기존 B.6 설정 | Modal | 검증 손실 감소, 체크포인트 저장 | 4시간 (무인) |
| 6.4 평가 | 새 장면 100개, 닫힌 루프 + 첫 프레임만 | 로컬/Modal | 성공률, 다른 블록 비율, 평균 오차, 영상 격자 | 2시간 |

**판단 시점**

- 6.1 실패: VLA를 중단하고, IK 정답 시연 영상만 보여줍니다.
- 6.2 실패, 또는 비용이 예상의 2배 이상: 원인을 보고하고 본 학습은 하지 않습니다.
- Day 7 오전까지 6.3을 시작하지 못하면: VLA는 로드맵으로 넘깁니다.

## 7. 실물 테스트 방식

학습은 가상 카메라 이미지로 하므로, 실물 테스트는 **디지털 트윈 방식**으로 합니다. 실물 블록을 매트 점에 놓고 같은 배치를 시뮬레이션에 입력하면, VLA가 가상 이미지를 보고 관절 명령을 내고, 그 명령을 실물 로봇으로 보냅니다. 영상과 README에는 "실물 카메라 영상은 쓰지 않았다"고 밝힙니다. 실물 카메라를 쓰는 B2는 보류합니다.
실물 세션 절차(배치·보정 유지·버튼 순서)는 `physical_session.ko.md`를 따른다.
