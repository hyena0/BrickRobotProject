# 5A단계: 시뮬레이션에서 관절 범위와 안전 자세

**Latest:** Day 4 · **필요 조건:** 5단계의 코드 생성과 시뮬레이션 리허설 (완료). **하드웨어 사용 안 함.**

**목표:** 추론된 모델로 쓸 수 있고 안전한 IK가 나오는지 시뮬레이션에서 증명합니다. 관절 범위를 모델 자체(센서 형상, 충돌, 여러 관절의 접힘)에서 추론하고, IK와 생성 코드에 적용하며, 5C단계 실물 재현용 안전 자세 세트를 만듭니다.

**기존 문서와의 관계:** 5단계 문서(그대로 유지)는 코드 생성과 실물 실행을 다룹니다. PLAN v2에서는 5단계를 시뮬레이션 수준에서 마무리하고, 실물 단계(5.3~5.4)는 5B단계 하드웨어 연결 이후 5C단계에서 수행합니다.

## 출발점

- 생성 코드와 시뮬레이션 리허설: 관절 자세 5개 오차 0, 직교 좌표 목표 6개 중앙값 1.92mm.
- Blender 자세 검증 (자세 10개): 지지 구멍, 링크를 넘는 기어 간격, FK 모두 통과. 범위가 아직 ±180°라 **10개 모두 자기 충돌**.

## 작업

### 5A.1 형상으로 구한 센서 경계 · `src/limits/sensor_bounds.py`

`config/ports.local.yaml`의 센서마다 2.7단계의 센서 ↔ 관절 대응을 사용합니다.

1. **누르는 부품 후보:** 관절의 움직이는 쪽 부품 중 회전 경로가 센서 작동 영역에서 10mm 안을 지나는 부품 (터치: `axis_local` 방향 버튼 끝, 컬러: `axis_local` 방향 시야, 20mm 이내).
2. 다른 관절은 원점 자세로 두고 해당 관절을 0.5°씩 양방향 **회전**. 경계 = 누르는 부품이 작동 영역에 처음 닿는 각도.
3. 기록: 관절, 경계 각도, 원점 복귀 방향, 누르는 부품 uid → `runs/stage5a/sensor_bounds.json` (비공개).
4. **컬러 센서:** 움직임을 막을 때만 `limit`, 아니면 `reference` (영점만 정함).

### 5A.2 충돌 경계 · `src/limits/collision_bounds.py`

- 원점에서 각 관절을 센서 반대 방향으로(J5는 양방향) 첫 충돌까지 회전.
- **충돌 기준:** 다른 링크 부품 사이 BVH 침투 1mm 초과. 원점에서 이미 있는 접촉(레고 특유의 딱 맞는 결합), 설계된 기어 맞물림, 관절 지지 부품은 제외.
- 경계 = 첫 충돌 − 5°.

### 5A.3 관절 간 제약 · `src/limits/coupled.py`

- 대상 쌍: 5단계 자세 보고서에서 접힘 충돌이 나온 쌍 (최소 J2–J3, 접촉 10개 이상인 쌍).
- 쌍마다 5A.1/5A.2 범위 안 5° 격자, 나머지 관절은 원점과 대표 손목 자세 3개 → 보수적인 선형 부등식 (예: `a·q2 + b·q3 ≥ c`).
- 무작위 전체 자세 2,000개로 검증: **허용된 자세 중 충돌 0개**, 포기한 자유 공간 비율 보고.

### 5A.4 모델 반영과 적용

- 형식과 모델: `limits_deg`, `limit_source` (`sensor` / `collision`, `measured`는 5C단계에서 추가), `home`, `coupled_limits`:
  ```json
  "joints": [{"id": "J2", "limits_deg": [lo, hi],
              "limit_source": {"lo": "sensor", "hi": "collision"},
              "home": {"sensor": true, "direction": "+"}}],
  "coupled_limits": [{"joints": ["J2", "J3"], "a": [1.0, 1.0], "b": -120.0, "op": ">="}]
  ```
- 동작 범위 = 센서 경계 − 5° (평소 동작에서는 센서를 누르지 않음).
- IK는 범위와 관절 간 제약 안에서 풀고, `is_path_safe(q_from, q_to)`가 5° 이하 간격 중간 자세를 검사 (범위, 부등식, BVH).
- `generated/robot_inferred/`를 다시 생성해 `robot_config.py`와 `motion.py`가 범위를 담고 적용하게 함.

### 5A.5 안전 자세 세트 · `runs/stage5a/poses10_safe.json`

- 작은 자세 5개(각 범위의 30% 이내) + 큰 자세 5개. 모든 자세와 원점에서의 경로가 충돌 없음, 범위·부등식 안, 끝단이 책상 위 40mm 이상.
- 렌더를 `assets/private/renders/poses_safe/`에 저장.

### 5A.6 로봇 패키지 v0 · `src/package/build.py` → `packages/<robot>/robot_package.json`

로봇 패키지는 컨트롤러 패키지의 유일한 실행 입력입니다 (PLAN v2 5절).

- 형식은 `docs/robot_package.md`에 정리하고 `schema_version` 필드를 둠.
- 이 단계의 v0 내용: 추상 기구학(축, 링크 치수, `C`), 근거가 붙은 `limits_deg`, `coupled_limits`, 동작 여유, 안전 자세, 속도 상한.
- 5C단계에서 추가: 포트 배선, 원점 복귀 설정, 영점 오프셋, 측정 범위 (바뀔 때마다 `package_version` 증가).
- 메시, 부품 uid, 부품 위치 없음: 모바일에서도 가볍고, PLAN v1 4a절 기준으로 공개 가능.
- 실행 중 충돌 안전은 `limits_deg`와 `coupled_limits`만으로 판단. 메시·BVH 검사는 PC 저작 도구에만 둠.

#### 패키지 내용 제약 (검증기가 강제)

**허용**

| 항목 | 내용 |
|---|---|
| 기구학 | 관절축, 관절 위치, 링크 치수, `C`, 끝단 위치 |
| 범위 | 근거가 붙은 `limits_deg`, `coupled_limits`, 여유, 속도 상한 |
| 안전 자세 | 관절 각도 목록만 |
| 하드웨어 | 포트 배선 (모터·센서 id → 브릭, 포트), 원점 복귀 설정, 영점 오프셋 (5C에서 추가) |
| `link_envelopes` (선택) | **링크마다 방향이 있는 상자 최대 1개**: `{link, center_mm, size_mm, orientation}`. UI 표시와 간격 안내 용도로만 사용 |

**금지** (검증기가 패키지를 거부)

- 메시, 꼭짓점·면 목록, 점군, 볼록 껍질, 링크당 상자 1개를 넘는 모든 형상 정보.
- 부품 id, 부품 이름, 부품 위치, 부품 수, 색상, 하위 모델·하위 조립 이름.
- 이미지, 렌더, 텍스처, `assets/private/`를 가리키는 파일 참조.
- 원 설계를 설명하는 자유 문구 (설계 이름과 출처는 README에만).

**한도**

- 상자 치수는 1mm, 방향은 1° 단위로 반올림.
- 패키지 파일 100KB 이하.
- `link_envelopes`는 PC 저작 도구가 비공개 모델에서 계산해 숫자로만 기록. 모델 자체는 `assets/private/` 밖으로 나가지 않음.

검증기: `python -m src.package.validate packages/<robot>/robot_package.json` (형식 검사 + 금지 항목 검사 + 크기 검사). 테스트와 모든 패키지 저장 전에 실행.

#### 비공개 시각 팩 (개발, 테스트, 영상 전용)

동작을 눈으로 확인하고 데모 영상을 만들려면 실제 레고 형상이 필요하지만, 배포해서는 안 됩니다. 그래서 로봇 패키지가 아닌 **별도의 비공개 시각 팩**에 둡니다.

- 위치: `assets/private/visual_pack/<robot>/` (git 제외). 링크마다 간략화한 메시 하나(`.glb`, 링크 좌표계 기준, Blender에서 내보냄) + `manifest.json` (링크 id → 파일, 메시와 링크 사이 변환, 대응하는 패키지 버전).
- `src/viz/export_visual_pack.py`가 2단계 링크 분할로 생성. 브라우저에서 부드럽게 보이도록 전체 20만 삼각형 이하.
- 로봇 패키지는 시각 팩을 참조하지 않으며, 위 검증기 규칙은 그대로 유지.
- 5C단계 콘솔의 비공개 표시 모드와 Blender 렌더에서만 사용. 커밋하지 않고, `src/ui/`에 포함하지 않고, `packages/`로 복사하지 않음.
