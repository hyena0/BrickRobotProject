# 5단계: 실물 로봇

**Latest:** Day 6 · **목표:** 추론된 모델로 EV3 제어 프로그램을 생성하고, 실물 팔을 지정한 목표로 움직입니다.

## 설계

- **PC:** IK와 모터 공간 변환 (4단계).
- **브릭:** 생성된 프로그램이 0단계 브릭 서버 위에 동작 기능을 더합니다. 여러 모터 동기 이동과 소프트 범위 제한입니다.
- 생성되는 부분은 기구학 모델에서 만든 상수와 루틴 파일입니다. 로봇이 바뀌면 손으로 고치지 않고 다른 프로그램이 생성됩니다.

## 작업

### 5.1 코드 생성기 (약 2시간) · `src/codegen/`

`generated/<robot>/`을 생성합니다.

- `robot_config.py`: 관절 목록, 범위, `C`, 구동기 대응(브릭, 포트, 모터 종류), 속도 상한.
- `motion.py`: `move_joints(q_target, duration)`. 모터 목표로 변환하고 `run_targets`를 보내 모든 모터가 함께 출발하고 함께 도착 (모터별 이동량에 맞춰 속도 조정).
- `home.py`: 원점 복귀 루틴. 센서 ↔ 관절 대응과 원점 복귀 방향은 에이전트 추론 결과(2.7)를 씁니다. 원점 복귀 이동마다 브릭의 원점 복귀 가드(`home_motor`)를 사용해, 센서가 감지되면 브릭에서 바로 모터를 멈춥니다. 센서가 없는 관절은 정지 감지 가드를 씁니다.
- `guards.py`: 모든 이동 전에 `set_guards`로 각 브릭에 보내는 가드 목록. `ports.local.yaml`의 모든 센서 → 원점 복귀가 아닐 때 감지되면 전체 정지.

생성된 파일은 공개합니다 (추상 기구학 + 코드, 부품 uid 없음).

### 5.2 영점 오프셋 · `config/homing.local.yaml`

- 각 원점 위치에서 모델 영점 자세까지의 오프셋, 필요하면 컬러 센서 기준값.
- **사람이 제공한** 보정값입니다. README에 명시합니다.

### 5.3 실행 순서

1. 모든 관절 원점 복귀.
2. 관절 하나씩 +15° 움직여 방향이 모델과 맞는지 확인. 부호가 틀리면 생성된 코드를 고치지 말고 **모델**을 고치고 기록합니다.
3. 관절 공간 자세 5개로 이동했다가 복귀.
4. 책상에 표시한 직교 좌표 목표 5~10개로 이동 (위치 전용 IK).
5. 목표마다 3번 반복해 반복 정밀도 측정.

### 5.4 측정

- 베이스 기준 좌표를 아는 목표점을 종이에 표시.
- 목표마다 끝단 오차를 자로 측정 (mm).
- 모든 실행을 고정 삼각대 각도에서 촬영 (영상에 필요).

## 안전

- 첫 전체 실행은 속도 상한 30%.
- 소프트 범위는 모델 값에서 양쪽 5°씩 좁힘.
- 모든 스크립트에서 비상 정지 키 활성화.
- 부하에서 기어가 미끄러지는지 관찰. 튀면 속도를 낮춤.

## 완료 기준

- [ ] 모든 이동 전에 가드가 활성화됨 (로그에서 `set_guards` 응답 확인).
- [ ] 평소 이동 중 센서를 손으로 누르면 팔이 멈추고, `clear_latch`와 재원점 복귀가 필요함.
- [ ] 원점 복귀가 3번 연속 성공.
- [ ] 모든 관절 방향이 모델과 일치.
- [ ] 팔이 모든 직교 좌표 목표에 도달하고 오차 기록 (기준값 없음. 레고 백래시는 예상된 부분).
- [ ] 쓸 수 있는 영상 확보.
